## 1. New this cycle: KBPRO — the closest three-sided-marketplace analog found so far

Search for Polish marketplace/platform terms surfaced **KBPRO**, described in its own marketing as a "cyfrowy ekosystem budowlany" (digital construction ecosystem) intended to connect all participants in the investment process. Per search snippets, it combines a cost calculator, a job/tender exchange (job exchange with marketplace-style listings), an e-shop partner feature for materials, and equipment-rental and settlement functions in one product.

This is notable because every prior report in this series (07-06 through 09-14) concluded that no competitor — Polish or international — combined a multi-party bidding marketplace with a wholesaler/materials role and estimating in one workflow. KBPRO's stated scope (calculator + job exchange + e-shop + equipment rental + settlements) is the first player found across five research cycles whose *described* feature set touches all three of Matadora's participant roles (something like investor-side job listings, contractor-side bidding/exchange, and wholesaler-side e-shop), rather than just one or two.

**Caveat — this needs direct verification before being treated as a real competitive threat.** A direct fetch of kbpro.com.pl was blocked by this session's network egress policy, so nothing here is confirmed against the live product: no pricing was found, no evidence of VAT-staged (8%/23%) estimating, and no mention of KSeF integration in the snippets available. It is entirely possible KBPRO's marketplace is a materials/equipment directory with a job board bolted on, rather than a true bid-accept-execute-invoice loop like Matadora's offer flow. Treat this as "worth a direct look," not as a confirmed overlapping competitor.

## 2. KSeF rollout: API 2.0 open testing underway, format change relevant to construction invoicing

Confirming and extending the 09-14 report's KSeF timeline tracking:

- The Ministry of Finance opened **KSeF 2.0 API open testing on 30 September 2025**, giving accounting/ERP software vendors (including anyone maintaining a KSeF integration module) a live target to validate against ahead of full enforcement. The 2.0 API introduces the **FA(3) structured-invoice format** with a new attachment node, plus **offline24** operating modes not present in the original KSeF 1.0 API.
- **New construction-specific detail this cycle:** from 2027, simplified invoices with only a NIP (tax ID) will no longer count as valid B2B invoices — every B2B transaction, regardless of amount, will require a full structured KSeF invoice. A dedicated resource site, **ksefdlabudownictwa.pl** ("KSeF for construction"), exists specifically to track how this phases in for construction firms across 2026-2027, which is itself a signal that the market treats "KSeF compliance for construction businesses" as a distinct enough problem to warrant its own vertical content — the same niche Matadora's `src/lib/ksef/` module and finance flow sit in.
- The previously-tracked milestones are unchanged: Feb 1, 2026 mandatory for large taxpayers (>200M PLN), Apr 1, 2026 mandatory for most other VAT-registered businesses (both now in effect), and Jan 1, 2027 for micro-taxpayers.

**Why this matters:** if Matadora's KSeF module was built against the 1.0 API, it's worth confirming there's a migration path to the FA(3)/2.0 API and offline24 modes before those become the only supported integration surface — this is a technical/compliance item, not a competitive one, but it's the kind of gap a Polish-native competitor (budow.app, Comarch, InsERT — all previously tracked as having live KSeF integrations) could use to claim "more current" compliance if Matadora lags the API version.
Sources: [ksef.podatki.gov.pl — Etapy wdrożenia KSeF 2.0](https://ksef.podatki.gov.pl/etapy-wdrozenia-ksef/), [KSeF dla Budownictwa — faktury uproszczone 2026-2027](https://ksefdlabudownictwa.pl/faktury-uproszczone-w-ksef-co-zmieni-sie-dla-firm-budowlanych-w-latach-2026-2027/), [ksef.podatki.gov.pl — Pytania i odpowiedzi KSeF 2.0](https://ksef.podatki.gov.pl/pytania-i-odpowiedzi-ksef-20/)

## 4. Suggestions

1. **Get a direct look at KBPRO before drawing conclusions from it.** This report's KBPRO profile is snippet-derived only (its site was unreachable from this research environment) — someone with normal browser access should check kbpro.com.pl directly for pricing, whether its "job exchange" is genuinely a bid-accept-execute loop or just a listings board, and whether it has any VAT-aware estimating or KSeF integration. If its marketplace is as broad as its marketing copy suggests, it's the first genuine three-sided-marketplace comparable found in five research cycles and deserves a proper feature-by-feature comparison; if it turns out to be a materials directory with a job board, it can be filed alongside the tender-aggregator sites and de-prioritized.

2. **Track the KSeF 2.0 / FA(3) API migration as a compliance roadmap item, not just a "have KSeF or not" checkbox.** With open API testing live since September 2025 and a construction-specific simplified-invoice phase-out coming in 2026-2027, the bar for "KSeF integration" is moving from a binary feature to a versioned compliance surface. Confirming `src/lib/ksef/` targets the current API generation (and has a plan for FA(3)/offline24) is now concrete, checkable work rather than a hypothetical future requirement.

3. **The three-sided marketplace + staged-VAT estimate + KSeF combination is still the clearest surviving differentiator across five research cycles (07-06 through this report)** — with the caveat that KBPRO is the first player whose stated scope even approaches all three legs at once and hasn't yet been directly verified. Rather than treating the differentiator as permanently secure, this is a good moment to actually verify the nearest-looking competitor directly (per suggestion 1) before continuing to lean on "no one combines all three" as settled fact in outward-facing material.
